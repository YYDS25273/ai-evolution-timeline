## 1. 背景

桌面已有上一轮完成的时间线原型：150 个节点、84 个来源站点、暗色横向时间轴，带搜索、时代/类型筛选、三档缩放、迷你地图与详情抽屉。它已覆盖 1943–2026 年 AI 史，并且包含用户点名的「OpenAI 2026 年 10 月公开 722 篇数学手稿」节点。

本次不是重做，而是在现有成果上做三件事：

1. 把时间线起点改为 **1966 年 ELIZA**，聚焦「语言/对话系统 → 大模型 → 智能体」的主线；
2. 对 2025–2026 的高风险节点做事实核查与纠错；
3. 补齐工程化文件，发布为公开 GitHub 仓库并启用 GitHub Pages。

## 2. 目标与非目标

### 目标

- 产出一条从左到右、可交互、可在手机与桌面浏览的 AI 发展时间线。
- 第一个节点为 1966 年 ELIZA，最后节点不晚于 2026-11-17。
- 138 个节点，全部带至少一个可点击来源。
- 对关键近期事件标注准确日期与口径，避免把厂商宣传或单一媒体消息写成定论。
- 以公开仓库 + GitHub Pages 的形式交付，README 含预览图、数据说明与构建方法。

### 非目标

- 不追求「互联网上所有 AI 新闻」的穷举；不做无来源的传闻汇编。
- 不重建视觉风格，不引入 React/Vite 等运行时框架。
- 不实现后端、账号、评论、数据库或实时抓取。
- 不覆盖 1943–1965 的完整前史；只在 README 与「关于」中保留简述。

## 4. 内容范围与事实核查

### 4.1 时间范围

- 保留 `dt >= 1966-01-01` 的节点，删除 1943–1965 的 12 个节点。
- 现有 150 个节点 → 删除后 **138 个节点**。
- 删除的 12 个节点：M-P 神经元、控制论、赫布规则、图灵测试、SNARC、达特茅斯提案、达特茅斯会议、GPS、感知机、LISP、塞缪尔跳棋、DENDRAL。
- 在 README 与「关于」中用一段「前史」概述这些内容，不进入主时间线。

### 4.2 时代划分

| id | 名称 | 年份 | 说明 |
|---|---|---|---|
| dawn | 早期对话系统 | 1966–1969 | ELIZA 与单层感知机的极限 |
| winter | 寒冬与专家系统 | 1970–1992 | 两次寒冬，专家系统的黄金年代 |
| stat | 统计学习前夜 | 1993–2011 | 核方法、深蓝与深度信念网络 |
| deep | 深度学习革命 | 2012–2017 | AlexNet、AlphaGo 与 Transformer |
| llm | 大模型时代 | 2018–2022 | 预训练、缩放律与 ChatGPT |
| gen | 生成式爆发 | 2023–2024 | GPT-4、多模态与全球监管 |
| agent | 智能体与前沿竞赛 | 2025–2026 | 推理模型、长程智能体与 AI 科学家 |

### 4.3 选材标准

优先收录：

- 开创性论文或系统；
- 里程碑模型/产品发布；
- 可量化的科研、产业、商业、教育、医疗结果；
- 改变规则的政策与治理事件。

不收：

- 同一事件的重复传闻；
- 未证实的能力宣称；
- 纯营销口径、无法定位原始出处的「据说」；
- 只有单一匿名来源且无法交叉验证的爆料。

每个节点至少 1 个来源；官方公告优先，其次 Nature/Science/arXiv、监管文件、投行/咨询报告、主流媒体。

### 4.4 已发现的重点修正

#### OpenAI 722 篇数学手稿

- GitHub 仓库 `openai/math` 创建于 **2026-10-06T21:47:02Z**。
- 发布时对外口径为 **722 篇手稿 / 372 个成果族**；随后撤回 3 篇、修订 14 篇。
- 截至 **2026-11-17**，仓库 README 写的是 **721 篇手稿 / 373 个成果族**，约 **42%** 的顶线结果有 Lean 形式化。
- 处理方式：标题保留用户熟悉的「722 篇」，正文写清「发布时 722 篇，现为 721 篇；372 → 373 个成果族；约 42% 顶线结果形式化」。
- 同时保留限制说明：Lean 覆盖不是全部，未形式化结果可能有问题，这是原始研究数据而非完成同行评审的论文。

#### GPT-6 Astra 日期

- 现有节点写 2026-09-29；检索到的官方与多家报道指向 **2026-09-03/04** 发布。
- 2026-09-22 追加 GPT-6 Sol / Luna；2026-09-29 是 **GPT-6.1 Sol**。
- 处理方式：Astra 首发节点改为 **2026-09-03**，正文注明「9 月 4 日扩大可用」；另设 2026-09-22 与 2026-09-29 节点，避免把 09-29 误标为 Astra 首发。

#### Gemini 4 Carbon

- 2026-10-28 发布，先向网络安全防御者与受信伙伴开放；2026-11-11 扩大到开发者、企业、科学家与 AI Ultra 订阅者。
- 处理方式：拆成两个节点——**2026-10-28 发布**、**2026-11-11 全面开放**；不把 11-10 写成首发。

#### Anthropic IPO

- 2026 年 6 月已保密递交；11 月为更新招股书/路演阶段，口径为约 **1.02 万亿美元**基本市值、最高约 **1.4 万亿美元**完全稀释市值。
- 处理方式：节点标题用「启动 IPO 路演：基本市值约 1.02 万亿美元」，正文写清完全稀释约 1.4 万亿美元，不写成「首次递交」。

### 4.5 核查与标注规则

- 官方页面与现有节点冲突时，以官方页面为准。
- 官方页面不可访问时，采用至少两家独立来源一致的日期；仍不一致则保留最保守表述，并在说明中写「口径存在差异」。
- 「关于」页新增「核验方法」段落，说明官方口径、机构数据、媒体报道三类来源的区别。
- 不新增彩色可信度徽章；可信度通过来源数量、措辞与说明体现。
- 所有修正记录写入 `docs/verification-notes.md`，包含日期、结论、来源链接。

## 5. 数据模型

事件对象字段：

```js
{
  dt: "2026-10-06",        // ISO 日期，唯一，必须 >= 1966-01-01
  d: "2026.10",            // 展示日期
  era: "agent",            // 7 个时代之一
  cat: "science",          // 8 个类型之一
  t: "标题",                // 必填，不重复
  f: true,                 // 可选，关键节点
  org: "OpenAI",           // 可选，机构/人物
  s: "一句话摘要",           // 必填
  x: "详细说明",             // 可选，可含换行
  n: [["722","篇手稿"]],    // 可选，关键数字
  tags: ["数学","Lean"],    // 可选
  src: [["来源名","https://..."]] // 至少 1 条
}
```

类型 `cat`：`theory`、`model`、`science`、`industry`、`infra`、`policy`、`app`、`safety`。

校验规则：

- `dt` 匹配 `YYYY-MM-DD`，且在 1966-01-01 与 2026-11-17 之间；
- `era`、`cat` 必须在白名单内；
- `t`、`s` 非空，`t` 不重复；
- `src` 至少 1 条，URL 以 `http://` 或 `https://` 开头；
- 事件总数必须为 138（若核查后增删，需同步更新 README 与「关于」）。

## 6. 架构与数据流

```text
src/part1.js … part5.js
        │  （事件数据，JS 对象数组）
        ▼
   build.mjs
        │  读取 src/template.html，替换 /*__EVENTS__*/，校验字段
        ▼
index.html  +  AI发展史时间线.html（同一份内容的本地副本）
        │
        ▼
GitHub Pages（main 分支根目录）
```

- 纯静态，无运行时依赖，无网络请求即可完整打开。
- `build.mjs` 在写入前完成校验；校验失败直接退出，不产出半成品。
- 页面数据在构建时内联，避免 fetch/JSON 加载失败。
- 搜索、筛选、缩放、抽屉全部在前端内存中完成。

## 11. 风险与应对

| 风险 | 应对 |
|---|---|
| 2026 年数据仍在变化（如 722/721 篇） | 标题保留用户熟悉口径，正文写「截至日期 + 最新数字」，并在 README 标注数据截止日 |
| 部分厂商官网被网络策略拦截 | 不以运行时抓取为准；构建时使用可访问的官方/权威来源，必要时用两家独立来源交叉验证 |
| 单一媒体来源可能有误 | 关键节点至少两源；只有单源时在说明中标注「单一来源」 |
| 历史节点删除后页面显得突兀 | 「关于」与 README 补「前史」段落，说明 1943–1965 的内容 |
| GitHub Pages 首次部署有延迟 | 发布后轮询线上地址，最多等待数分钟；必要时检查 Pages build 状态 |
| 中文文件名在部分环境编码异常 | 以 `index.html` 为规范入口，中文名仅作本地副本 |
